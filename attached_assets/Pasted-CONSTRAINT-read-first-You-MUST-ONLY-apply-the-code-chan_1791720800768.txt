getSubServices(serviceValue: string): SubServiceDef[] — exact match on ServiceDef.value, else [].
getServiceLabel(stored: string | undefined, t: (key: string) => string): string — returns "" for empty. Otherwise: (1) exact case-insensitive/trimmed match on a ServiceDef.value -> t(labelKey); (2) if the lowercased stored value contains "nephrology" or "الكلى" -> t("service.nephrology") (historical standalone Nephrology visits keep their own label); (3) the first ServiceDef (in order) whose terms match as substrings -> t(labelKey); (4) otherwise return the stored string unchanged.
matchesServiceFilter(mainService: string | undefined, subService: string | undefined, serviceValue: string, subValue: string): boolean —
  * serviceValue empty -> true.

  * Main match: find the ServiceDef whose value === serviceValue; true if lowercased mainService contains any of its terms; if no ServiceDef is found, fall back to lowercased substring match of serviceValue.

  * subValue empty -> main match result. Otherwise additionally require a sub match: stored subService (lowercased, trimmed) equals subValue (lowercased) OR equals one of that SubServiceDef's aliases OR (the SubServiceDef has legacyMainTerms and the lowercased mainService contains one of them). The value "Other" (no SubServiceDef) matches by case-insensitive equality only.

PHASE 3 — ONE-TIME DATA MIGRATION FROM localStorage
═══════════════════════════════════════════════
1. Create src/lib/db/migrateFromLocalStorage.ts exporting 
   `migrateLegacyDataIfNeeded(): Promise<{ migrated: boolean; counts: Record<string, number> }>`.
2. Logic:
   a. Check a new localStorage flag `yaqoot_sqlite_migration_done`. If 
      already `"true"`, return `{ migrated: false, counts: {} }` immediately 
      — never re-run.
   b. If not set: read all 7 legacy localStorage keys using the untouched 
      logic from repository.legacy.ts (import its getList-equivalent, or 
      inline the same JSON.parse pattern).
   c. If localStorage has zero patients (fresh install, nothing to migrate), 
      skip straight to marking the flag as done — do not seed empty tables 
      unnecessarily.
   d. Otherwise, insert all records into SQLite inside a SINGLE SQL 
      transaction (`BEGIN` → inserts → `COMMIT`, with `ROLLBACK` on any 
      error). Preserve exact ids/timestamps — this is a data carry-over, not 
      a re-creation.
   e. After the transaction commits successfully, run a verification count: 
      `SELECT COUNT(*) FROM patients` (and each other table) and compare 
      against the original localStorage array lengths. If ANY count 
      mismatches, throw an error, do NOT set the migration flag, and leave 
      localStorage data untouched (so the app keeps working on legacy data 
      via repository.legacy.ts fallback — see Phase 4 step 4).
   f. Only after verified counts match: set 
      `localStorage.setItem('yaqoot_sqlite_migration_done', 'true')`. Do NOT 
      delete the original localStorage keys yet — keep them as a cold backup 
      indefinitely (they cost negligible space and are the safety net).
3. Call `migrateLegacyDataIfNeeded()` once at app bootstrap, before rendering 
   DataProvider's children, and await it (show a simple "Preparing 
   database..." loading screen during this — first-run migration should be 
   near-instant for typical clinic data volumes, but must not race with 
   renders reading empty state).

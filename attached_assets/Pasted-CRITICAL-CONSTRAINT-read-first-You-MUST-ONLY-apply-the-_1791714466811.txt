STEP 1 – Create src/lib/homeContent.ts (pure TS, no React)
- export const HOME_TEXT_MAX_LENGTH = 600; export type HomeTextKind = "vision" | "mission"; export type HomeLocale = "ar" | "en".
- Storage key for a text: `yaqoot:home:${kind}:${locale}` (e.g. "yaqoot:home:vision:ar"). Texts are stored PER LANGUAGE.
- getHomeText(kind, locale): string | null — saved trimmed text or null if missing/empty.
- setHomeText(kind, locale, text): boolean — trims; empty after trim removes the key (restores default) and returns true; otherwise saves. Returns false if localStorage throws.
- clearHomeText(kind, locale): boolean — removes the key; false if it throws.
- exportHomeContent(): Record<string, string> — returns an object containing ONLY the saved entries, keyed "vision:ar", "vision:en", "mission:ar", "mission:en" (so it is `{}` when nothing was customized).
- importHomeContent(value: unknown): void — if value is not a plain object, do nothing. Otherwise, for each of the four allowed keys: first remove the local key, then if value[key] is a string whose trim is non-empty and length <= HOME_TEXT_MAX_LENGTH, save the trimmed string. Ignore any other keys. Never throw (wrap in try/catch). Semantics: when a backup contains `homeContent`, the app state after restore equals the backup's state.
- Every localStorage access wrapped in try/catch.
